The whole genome

Load a whole bundle, or pick single elements from /elements. Either way the core goes first. Pick a component to see it working in a real screen.

lwt-general.jsLayout, navigation and feedback

Resizable workspaces, tabs, trees, modals and toasts. The building blocks every app screen needs, styled once through CSS variables.

lwt-forms.jsForms that do the hard parts

Date ranges, phone numbers, signatures and file uploads, with validation built in. Each field submits with a normal <form> and exposes a typed .value. Use a scene and watch the readout.

lwt-dashboard.jsCharts without a charting library

Fourteen chart and KPI elements drawn as inline SVG. Give them Chart.js-shaped data through .data and they redraw whenever it changes. Hover any mark for its values.

lwt-core.cssRestyle everything with a few variables

Every component reads the same design tokens, so changing them once restyles all of them. Any component can still be overridden on its own, for example with --lwt-alert-gap.

Add it to a page in about a minute

  1. Load the core, then what you need

    The core always goes first. Then add a whole bundle, or only the element files you use from /elements.

    <!-- 1. Always: the core (and optional theme tokens) --> <script src="https://cdn.jsdelivr.net/gh/LWW-LWTECH/LWT-CORE-DNA@refs/heads/main/lwt-core.js"></script> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/LWW-LWTECH/LWT-CORE-DNA@refs/heads/main/lwt-core.css"> <!-- 2a. A whole bundle: every form element --> <script src="https://cdn.jsdelivr.net/gh/LWW-LWTECH/LWT-CORE-DNA@refs/heads/main/lwt-forms.js"></script> <!-- 2b. Or single elements only --> <script src="https://cdn.jsdelivr.net/gh/LWW-LWTECH/LWT-CORE-DNA@refs/heads/main/elements/lwt-frm-input.js"></script> <script src="https://cdn.jsdelivr.net/gh/LWW-LWTECH/LWT-CORE-DNA@refs/heads/main/elements/lwt-frm-phone.js"></script>

  2. Write the tags

    Attributes configure each component. There is nothing to import or initialise.

    <form id="signup"> <lwtf-input label="Email" name="email" type="email" required></lwtf-input> <lwtf-phone label="Phone" name="phone" default-country="US"></lwtf-phone> </form>

  3. Read typed values

    Validate a whole form in one call and get back arrays, numbers and Files.

    const form = document.getElementById('signup'); const check = LWT.form.validate(form); if (check.valid) { const data = LWT.form.getData(form); // { email: "…", phone: { country: "US", … } } }
