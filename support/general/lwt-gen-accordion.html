LWT-Core Accordion

Example Accordion

This is an example of the simplest implementation of an accordion.

Accordion Item 1
Content for Accordion Item 1
Accordion Item 2
Content for Accordion Item 2
 
<lwtg-accordion>
    <lwtg-accordion-item  id="accitem1">
        <div slot="label">Accordion Item 1</div>
        <div slot="body">Content for Accordion Item 1</div>
    </lwtg-accordion-item>
    <lwtg-accordion-item  id="accitem2">
        <div slot="label">Accordion Item 2</div>
        <div slot="body">Content for Accordion Item 2</div>
    </lwtg-accordion-item>
</lwtg-accordion>

Options

Attribute Description Application
multiple Allows multiple accordion items to be open simultaneously. Apply to the <lwtg-accordion multiple> element.
open Opens the accordion item by default. Apply to the <lwtg-accordion-item open> element.
disabled Disables the accordion item, preventing it from being opened. Apply to the <lwtg-accordion-item disabled> element.

Slots

Slot Description Application
label The label for the accordion item. Apply to the <div slot="label"> element inside <lwtg-accordion-item>.
body The body content for the accordion item. Apply to the <div slot="body"> element inside <lwtg-accordion-item>.

JS Methods

<script>
    let accitem1 = document.getElementById('accitem1');
    accitem1.open();
</script>
Method Description Application
open() Opens the accordion item. e.g., item.open();
close() Closes the accordion item. e.g., item.close();
toggle() Toggles the accordion item open or closed. e.g., item.toggle();
